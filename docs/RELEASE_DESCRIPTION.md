# Dynamic Lot Main Menu

Automatically show your last-played household's lot on The Sims 4 main menu.

The updater reads your newest local save, finds the active household's current/home lot, extracts the lot thumbnail stored in the save, and updates the included main-menu package before launch.

**No Python installation is needed for the Windows release.**

### Features

- Uses the last-played household from your newest save
- Automatically finds the matching saved lot thumbnail
- Creates a widescreen main-menu background
- Clears `localthumbcache.package` after updating
- Does not modify save files
- Optional Update & Launch shortcut

### Limitation

The background is updated before launch. It cannot switch live when you return to the main menu during the same game session. Save and exit, run the updater again, and relaunch.

### Tested version

The Sims 4 1.127.41.1030
